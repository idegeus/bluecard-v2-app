# Play Store-materiaal

| Bestand | Waar in de Play Console | Eisen |
|---|---|---|
| `icon-512.png` | Winkelvermelding → App-pictogram | 512×512 PNG |
| `feature-graphic-1024x500.png` | Winkelvermelding → Feature graphic | 1024×500, geen transparantie |
| `phone-nl/01…08-*.png` | Winkelvermelding → Screenshots telefoon | 2–8 stuks, 9:16, 1080×1920 |

De screenshots zijn opnames van de app (Nederlands) in een kader met een kop, gemaakt met `bron/compose.py`
(headless Chrome). Het icoon en de feature graphic komen uit `bron/icon.html` en `bron/feature.html`.
